# Screenshot baseline

Captured by `pnpm shots` (scripts/capture-screens.mjs) from the assembled
production site with a fixed clock (2026-01-15T10:30:00.000Z), blocked
cross-origin traffic, reduced motion, and seeded theme/language/family storage.

Regenerate after intentional visual changes and review the diff before
committing. Pixel diff thresholds are intentionally not enforced yet.

Matrix: 8 pages × 1 theme family (catppuccin) × 2 modes × 3 languages × 2 viewports.

Default run captures the catppuccin family only; use `--families` to add gruvbox/solarized passes without touching the committed baseline names.
